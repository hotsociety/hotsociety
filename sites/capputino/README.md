# Site do Cappu (capputino-hq.vercel.app)

Página estática (um `index.html`). Publicada pelo projeto **capputino-hq** da Vercel, ligado a este repositório
com **Root Directory = `sites/capputino`** (sem build). Toda alteração nesta pasta que entra na `main` publica o site.

O formulário "Aplicar para a mentoria" manda uma cópia das respostas para
`https://hotsociety.com.br/api/mentoria/aplicacao` (Painel → Mentoria, "lead insta cappu").

Publicado pela Vercel a partir deste repositório desde 29/10/2026.
